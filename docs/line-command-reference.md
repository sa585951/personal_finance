# LINE 功能對照表

此文件整理目前 LINE Bot 可用指令、對應 parser type、畫面形式與狀態。Phase 5.5 收尾後，LINE 端定位為快速記帳、查詢與帳戶操作入口；旅行帳本、進階報表與完整設定仍以 Web / 未來 App 為主。

## 建議輸入格式

LINE help 與 Web AI 快速輸入目前統一使用以下高頻句型，引導使用者先用最穩定的方式記帳：

- 一般支出：`午餐麥當勞 150 用現金`
- 補記支出：`昨天晚上晚餐麥當勞 150`、`6/13 午餐 120`
- 帳戶支出：`晚餐 680 用國泰信用卡`
- 收入：`薪資 50000 存入銀行`
- 外幣支出：`咖啡 5 美元 用美金現金`
- 查詢與操作：`本月支出`、`我的資產`、`我要轉帳`

若希望 LINE 自動扣款或入帳，需先新增對應帳戶，例如現金、銀行、信用卡或外幣現金。之後輸入 `晚餐 680 用國泰信用卡`、`薪資 50000 存入銀行`，系統才有機會對應到帳戶並更新餘額。

帳戶提示匹配會優先看完整名稱與上下文，例如 `國泰信用卡`、`國泰活存`、`國泰定存`。如果只輸入 `信用卡` 或 `銀行` 這類泛稱，且同類型帳戶不只一個，系統不應任意抓第一筆帳戶。

旅行帳本目前請開啟 Web 使用；LINE 端先定位為快速記帳、查詢與帳戶操作入口。

投資投入成本目前請用 `我要轉帳` 記錄到投資類型帳戶；Nomica 不會把投資買入當成一般支出，也不串接券商或追蹤即時市值。

限制：以上是建議輸入格式，不代表所有口語縮寫、多筆輸入、中英文混用或語音輸入都已完整支援；這些會留到後續 parser accuracy 與 App 輸入策略再處理。

## 暫停中

| 使用者輸入 / 舊入口 | 目前行為 | 暫停原因 |
| --- | --- | --- |
| `我的財務目標`、`我的目標`、`目標查詢` | 回到 help / 暫停提示 | Web 端已先暫緩，LINE 不應保留舊入口。 |
| `新增目標`、`設定目標` | 回到 help / 暫停提示 | 舊 goal flow 不符合目前 Phase 5 MVP 重點。 |
| `管理目標`、`編輯目標`、`目標進度` | 回到 help / 暫停提示 | 避免舊 schema 或舊產品方向混淆。 |
| `編輯目標:...`、`刪除目標:...` | 回到 help / 暫停提示 | 舊按鈕 payload 已停用。 |

## 後續討論方向

財務目標暫時不建議直接沿用舊設計。後續若要回歸，建議改成更貼近目前產品方向的功能：

1. 資金分配：記錄薪資或收入進來後，分配到生活費、旅費、投資、儲蓄等用途。
2. 投資投入成本紀錄：先只記錄投入成本與資金流向，不接券商、不追求即時市值。
3. 月度分配檢視：讓使用者看出收入如何被分配，不把投資做成完整券商資產管理。

此方向比舊的「財務目標」更接近日常記帳、旅行帳本與資產流向，也比較適合 MVP 之後逐步商品化。
