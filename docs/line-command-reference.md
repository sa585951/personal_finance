# LINE 功能對照表

此文件整理目前 LINE Bot 可用指令、對應 parser type、畫面形式與狀態。Phase 5 期間以 MVP 測試穩定性為主，未列為啟用的功能不應出現在 LINE help 選單。

## 啟用中

| 使用者輸入 / 入口 | Parser type | 回覆形式 | 說明 |
| --- | --- | --- | --- |
| 自然語言支出，例如「午餐麥當勞 150 用現金」 | `expense` | Flex 成功卡 | 直接建立支出，若有帳戶提示會同步扣款。 |
| 自然語言收入，例如「薪水 50000 存入銀行」 | `income` | Flex 成功卡 | 直接建立收入，若有帳戶提示會同步入帳。 |
| `快速記帳`、`新增支出` | `start_add_expense` | Flex 流程卡 | 手動新增支出流程。 |
| `紀錄收入`、`新增收入` | `start_add_income` | Flex 流程卡 | 手動新增收入流程。 |
| `查詢本月支出`、`統計`、`本月` | `query` | Flex 統計卡 | 顯示本月支出統計與最近交易。 |
| `我的資產`、`資產狀況`、`總資產` | `asset_query` | Flex 資產卡 | 依幣別顯示新版 accounts schema 的可追蹤帳戶餘額。 |
| `新增銀行帳戶`、`新增帳戶`、`加入帳戶` | `start_add_account` | Flex 流程卡 | 新增帳戶流程。 |
| `更新餘額`、`修改帳戶餘額`、`調整餘額` | `start_update_balance` | Flex 流程卡 | 更新帳戶餘額流程。 |
| `刪除帳戶`、`刪除資產`、`移除帳戶` | `start_delete_asset` | Flex 流程卡 | 軟刪除帳戶流程。 |
| `我要轉帳`、`轉帳`、`帳戶間轉帳` | `start_transfer` | Flex 流程卡 | 同幣別帳戶間轉帳流程。 |
| `刪除交易`、`刪除記錄`、`刪除支出` | `start_delete_transaction` | Flex 流程卡 | 刪除最近交易流程。 |
| `設定預算`、`新增預算`、`調整預算` | `start_set_budget` | Flex 流程卡 | 設定指定月份與分類預算。 |
| `幫助`、`說明`、`功能` | `other` | Flex help 卡 | 顯示目前可用功能入口。 |

## 暫停中

| 使用者輸入 / 舊入口 | 目前行為 | 暫停原因 |
| --- | --- | --- |
| `我的財務目標`、`我的目標`、`目標查詢` | 回到 help / 暫停提示 | Web 端已先暫緩，LINE 不應保留舊入口。 |
| `新增目標`、`設定目標` | 回到 help / 暫停提示 | 舊 goal flow 不符合目前 Phase 5 MVP 重點。 |
| `管理目標`、`編輯目標`、`目標進度` | 回到 help / 暫停提示 | 避免舊 schema 或舊產品方向混淆。 |
| `編輯目標:...`、`刪除目標:...` | 回到 help / 暫停提示 | 舊按鈕 payload 已停用。 |

## 後續討論方向

財務目標暫時不建議直接沿用舊設計。後續若要回歸，建議改成更貼近目前產品方向的功能：

1. 資金分配：記錄薪資或收入進來後，分配到生活費、旅費、投資、儲蓄等用途。
2. 投資投入成本紀錄：先只記錄投入成本與資金流向，不接券商、不追求即時市值。
3. 月度分配檢視：讓使用者看出收入如何被分配，不把投資做成完整券商資產管理。

此方向比舊的「財務目標」更接近日常記帳、旅行帳本與資產流向，也比較適合 MVP 之後逐步商品化。
